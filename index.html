01 / Faster regression feedback+

Make the wait shorter, not the checks weaker.

Context. A regression CI job took approximately 60 minutes, slowing down the feedback cycle.

My contribution. Reworked execution to use multiple concurrent workers and investigated failures through logs and test artifacts.

Result. The selected job ran in approximately 15 minutes. This is an improvement for one job, not a claim that the entire delivery pipeline became four times faster.

02 / Repeatable API regression+

Shared foundations before more test code.

Context. One company project relied on manual API regression work that could be made repeatable.

My contribution. Built nearly all of its automated API checks, using reusable Axios clients, fixtures, helpers, and explicit test-data setup and cleanup.

Result. Reduced repeated manual regression work and left a maintainable basis for future checks.

03 / A test ecosystem people can maintain+

Useful failures need shared ownership.

Context. A TypeScript ecosystem with 1,200+ specs and 11,000+ API and UI scenarios, shared by 10–15 QA automation engineers.

My contribution. Maintained and refactored shared code, reviewed changes, investigated flaky tests, created a Datadog dashboard, and led the TestRail-to-Testomat migration with documentation and standards.

Result. Better visibility and a more consistent way to maintain automation. The suite size describes the shared ecosystem, not tests authored by me alone.

Engineering notes

Three things
worth asking.

Practical ideas behind everyday quality decisions.

Quality engineering

Is this test worth keeping?

A useful check protects an important behavior and produces a failure someone can act on. If it is flaky or costly to maintain, fix its foundations or reconsider what it is testing. A bigger suite is not automatically a better one.

AI-assisted testing

Where does AI help?

Code exploration, test ideas, refactoring, and documentation are good starting points. Generated changes still need review and execution against real behavior. Faster drafting is useful; unverified confidence is not.

CI/CD

What does green actually mean?

Only that the checks which ran passed. Trust also depends on what they cover, what was skipped, how failures are investigated, and whether the result arrived soon enough to influence a decision.
